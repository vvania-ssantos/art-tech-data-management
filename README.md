# 💡 Sobre o projeto

O **Arte-Tech Data Management** nasceu da união entre duas áreas que normalmente caminham separadas: o artesanato e a tecnologia.

O projeto tem como objetivo desenvolver uma solução de gestão baseada em dados para um ateliê artesanal especializado na produção de peças em crochê, aplicando conceitos de Engenharia de Dados para organizar informações, apoiar decisões e tornar os processos mais eficientes.

Diferentemente de projetos acadêmicos construídos sobre cenários fictícios, este projeto utiliza um contexto real de negócio. Cada requisito, entidade e relacionamento foi pensado para representar situações presentes no cotidiano de um pequeno empreendimento artesanal.

Mais do que desenvolver um banco de dados, este projeto busca demonstrar como a tecnologia pode agregar valor a pequenos negócios por meio da organização das informações e da análise de dados.

---

# 📖 Contexto

À medida que a produção artesanal cresce, aumenta também a necessidade de controlar informações relacionadas a materiais, fornecedores, custos, clientes, encomendas e vendas.

Quando esses dados permanecem distribuídos entre anotações, planilhas ou registros informais, torna-se difícil responder perguntas importantes para a gestão do negócio.

O **Arte-Tech Data Management** surgiu justamente para transformar essas informações em uma base estruturada, capaz de fornecer indicadores e apoiar decisões de forma mais estratégica.

# 🎯 O problema

Pequenos empreendimentos artesanais frequentemente enfrentam desafios como:

- controle de estoque de materiais;
- cálculo do custo de produção de cada peça;
- acompanhamento de encomendas;
- gestão de fornecedores;
- histórico de clientes;
- controle financeiro das vendas;
- análise de lucratividade.

Sem uma estrutura adequada, essas informações ficam dispersas e dificultam tanto a organização operacional quanto a tomada de decisões.

---

# 🚀 A solução

O projeto propõe o desenvolvimento de uma solução de gestão baseada em um banco de dados relacional capaz de integrar informações sobre:

- 🧶 Materiais
- 📦 Produtos
- 👥 Clientes
- 🚚 Fornecedores
- 🛒 Vendas
- 📋 Encomendas
- 📦 Estoque
- 💰 Custos de produção

A partir dessa estrutura será possível realizar consultas SQL, gerar análises e, futuramente, construir dashboards e processos automatizados de apoio à gestão.

---

# 🎯 Objetivos

- Aplicar conceitos de modelagem de dados em um cenário real;
- Desenvolver um banco de dados relacional utilizando PostgreSQL;
- Consolidar conhecimentos em SQL;
- Organizar dados para apoiar decisões do negócio;
- Aplicar boas práticas de versionamento utilizando Git e GitHub;
- Evoluir o projeto continuamente utilizando uma metodologia baseada em Sprints.

# 🌱 Evolução do projeto

O Arte-Tech Data Management é um projeto vivo.

À medida que novas peças são produzidas, novos materiais são utilizados e novos processos são incorporados ao ateliê, o banco de dados evolui para representar fielmente a realidade do negócio.

Dessa forma, o projeto cresce simultaneamente em duas frentes: o desenvolvimento técnico em Engenharia de Dados e a evolução do próprio empreendimento artesanal.
